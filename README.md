# Digital

Минималистичный циферблат **Digital** для умных часов **Amazfit Balance 2** на платформе **Zepp OS** (API 3.0).

Показывает текущее время в формате `ЧЧ:ММ` крупным шрифтом с декоративной линией под цифрами.

## Возможности

- ⏱ Текущее время `ЧЧ:ММ` (крупный текст 96 px, центрированный по экрану)
- ➖ Декоративная линия под цифрами (canvas ZeppOS API 3.0)
- 🔋 Оптимизировано для AMOLED (минимальное потребление, без лишней анимации)
- 📊 Минимальная логика: обновление раз в минуту
- 🌙 **AOD-режим**: на затухшем экране показываются только приглушённые время и дата на чёрном фоне (защита от выгорания AMOLED и экономия батареи); кольца, секунды и кнопки автоматически скрыты через `show_level`

## Требования

- **Node.js** v18+ (проверено на v20+)
- **CLI ZeppOS** — установить глобально:

```bash
npm install -g @zeppos/zeus-cli
```

## Сборка и запуск

### 1. Установка зависимостей

```bash
npm install
# или если зависимости в проекте не нужны:
# zeus build сам подтянет SDK
```

### 2. Сборка проекта (production)

```bash
zeus build
```

Результат появится в `dist/` — файл вида `30001-Digital-1.0.0-*.zab`.

### 3. Предпросмотр в симуляторе (dev)

Для dev-режима с hot-reload:

```bash
zeus dev
```

> 🔧 **Совет:** перед запуском откройте симулятор ZeppOS (вариант имеет `simulator_2.1.2_window_x64.exe`). При первом запуске превью симулятор может кэшировать старую версию кода — при несовпадении логов перезапустите симулятор.

### 4. Запуск на устройстве

Подключите часы, затем:

```bash
zeus preview --watch
```

Либо соберите из `dist` по документации Zepp OS.
